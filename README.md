# 🌿 BelanjaBijak — Pemindai Label & Greenwashing (Full Multimodal AI)

Aplikasi web berbasis **Streamlit** dan **Google Gemini 3.8 Flash Vision** (dengan auto-fallback model) untuk memindai kemasan produk secara langsung tanpa pipeline OCR/Regex manual yang rentan salah baca.

## Cara Menjalankan di Komputer Lokal
1. Ekstrak folder ini dan buka terminal di dalam folder `BelanjaBijak_FullAI_v2`.
2. Install dependensi ringan:
   ```bash
   pip install -r requirements.txt
   ```
3. Jalankan aplikasi:
   ```bash
   streamlit run app.py
   ```
